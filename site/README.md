# Relay landing site

Static English (`index.html`) and Arabic (`ar/index.html`) pages, generated from the
Design canvas boards with `build_site.py` and hosted on Vercel (free `*.vercel.app` address).

When the signed APK is published, replace the "Download link coming soon" button in both
pages with a link to the release asset and add its SHA-256 (see `docs/android-release.md`).
